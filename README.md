# Rafaishifa - Authentic Unani & Tib-e-Nabvi Herbal Medicine Store

This repository contains the source code for Rafaishifa, an online store for authentic Unani and Tib-e-Nabvi herbal medicines.

## Features

- Browse herbal medicines and products
- Add items to cart and checkout
- Read Tib Blog & Remedies
- Admin dashboard for managing products
- Search functionality
- Mobile responsive design

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```
2. Set up environment variables:
   - Copy `.env.example` to `.env.local`
   - Add your Firebase configuration and Gemini API key
3. Run the app:
   ```bash
   npm run dev
   ```

## Build for Production

```bash
npm run build
```

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Firebase
- Lucide React Icons
